# OS Page Replacement Algorithm Visualizer (MERN)

## Quick Start

### 1. Start Backend (Node + Express + MongoDB)
```bash
cd backend
npm install
npm start
```
*(Ensure local MongoDB is running on `mongodb://127.0.0.1:27017/os_visualizer`)*

### 2. Start Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
